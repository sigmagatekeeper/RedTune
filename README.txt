RedTune - Anleitung
1. Neues GitHub-Repository erstellen (github.com/new), z. B. "RedTune".
2. Den kompletten INHALT dieses Ordners hochladen (Add file > Upload files),
   inklusive des versteckten Ordners .github.
3. Tab "Actions" > warten bis der Haken gruen ist > unten bei "Artifacts"
   "RedTune-VST3" herunterladen.
4. Ordner RedTune.vst3 nach C:\Program Files\Common Files\VST3\ kopieren.
5. FL Studio: Optionen > Manage plugins > Find installed plugins.

Travis-Scott-/Ufo361-Effekt: Retune Speed = 0, Amount = 100 %, Dry/Wet = 100 %,
Key/Scale passend zum Beat (oder Chromatic).
